# COREGAME - Casino Game Project

A professional mobile casino gaming application built with Flutter, designed for landscape gameplay.

## Features

- **Multiple Games**: Includes Roulette, Andar Bahar, 7 Up Down, Coin Flip, Limbo, Dice, Mines, Plinko, Crash, HiLo, and Twist.
- **Landscape Layout**: Optimized for mobile landscape orientation with a custom phone mockup for desktop viewing.
- **Premium UI/UX**: Retro-styled interfaces with custom animations, haptic feedback, and dynamic sound management.
- **Global State**: Centralized state management for user balance, VIP levels, and settings.
